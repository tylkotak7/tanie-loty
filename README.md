# Loty z POZ – apka na Androida

Okazje i szybkie wyszukiwanie tanich lotów z Poznania-Ławicy.

Każdy push na `main` buduje APK przez GitHub Actions i wrzuca go do zakładki **Releases**.
Na telefonie: Releases → najnowsza wersja → `LotyPoz.apk` → zainstaluj (zezwól na instalację z nieznanych źródeł).
